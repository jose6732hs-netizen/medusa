🔌 APIs REST (Dados em JSON)

Produtos:
  GET http://localhost:3000/api/produtos
  Retorna lista de todos os produtos com ID, nome, preço, estoque

Pedidos:
  GET http://localhost:3000/api/pedidos
  Retorna lista de pedidos com ID, cliente, status, valor total


💬 CHAT IA MULTI-TENANT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Enviar mensagem:
  POST http://localhost:3000/api/tenant/empresa1/chat
  Body: { "message": "Como posso ajudar?", "userId": "user123" }
  Resposta: Chat responde isolado por tenant

Ver histórico:
  GET http://localhost:3000/api/tenant/empresa1/chat
  Retorna histórico de conversas do tenant

🚀 COMO VER TUDO FUNCIONANDO
═══════════════════════════════════════════════════════════════════════════════

OPÇÃO 1 - Ver Storefront (recomendado para começar):
  1. Abra: http://localhost:3000
  2. Você verá a loja online com produtos
  3. Clique em "Adicionar ao Carrinho"

OPÇÃO 2 - Ver Admin Dashboard:
  1. Abra: http://localhost:3000/admin
  2. Você verá métricas e gestão de pedidos
  3. Customize do seu jeito!

OPÇÃO 3 - Testar APIs:
  Abra sua ferramenta favorita (Insomnia, Postman, curl):
  
  curl http://localhost:3000/api/produtos
  curl http://localhost:3000/api/pedidos
  curl http://localhost:3000/health

OPÇÃO 4 - Chat IA Multi-Tenant:
  curl -X POST http://localhost:3000/api/tenant/empresa1/chat \
    -H "Content-Type: application/json" \
    -d '{"message": "Olá!", "userId": "user1"}'


═══════════════════════════════════════════════════════════════════════════════
✨ PRÓXIMAS AÇÕES - CUSTOMIZAR DO SEU JEITO
═══════════════════════════════════════════════════════════════════════════════

1. ESTILIZAR:
   - Editar HTML/CSS no server.js
   - Mudar cores, fontes, layout
   - Adicionar sua marca

2. ADICIONAR DADOS REAIS:
   - Conectar banco de dados PostgreSQL/Neon
   - Importar produtos reais
   - Integrar pagamento (Stripe, etc)

3. FUNCIONALIDADES:
   - Adicionar carrinho persistente
   - Login/autenticação multi-tenant
   - Checkout completo
   - Relatórios avançados

4. PUBLICAR:
   - Deploy no Vercel
   - Seu e-commerce online!

📊 ESTRUTURA MULTI-TENANT
═══════════════════════════════════════════════════════════════════════════════

Cada tenant é completamente isolado:
  
  Empresa 1 (tenant="empresa1")
  └─ Seus produtos
  └─ Seus pedidos
  └─ Seus clientes
  └─ Seu chat IA

  Empresa 2 (tenant="empresa2")
  └─ Seus produtos
  └─ Seus pedidos
  └─ Seus clientes
  └─ Seu chat IA

Use URLs como:
  /api/tenant/empresa1/chat
  /api/tenant/empresa2/chat
  /api/tenant/seucliente/chat
