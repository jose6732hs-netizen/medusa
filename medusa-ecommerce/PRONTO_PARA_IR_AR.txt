🚀 COMEÇAR EM 3 PASSOS
═══════════════════════════════════════════════════════════════════════════════

PASSO 1: Configure as variáveis de ambiente
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  
  1. Abra o arquivo: .env.example
  2. Copie para:     .env.local
  3. Edite com:
     - DATABASE_URL do Neon (já conectado!)
     - NEXTAUTH_SECRET (gere com: openssl rand -base64 32)
     - NEXTAUTH_URL (seu domínio)


PASSO 2: Instale dependências e setup do banco
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  npm install
  npm run db:push


PASSO 3: Inicie o projeto
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  npm run dev

  Acesse: http://localhost:3000

🌍 DEPLOY EM PRODUÇÃO (2 OPÇÕES)
═══════════════════════════════════════════════════════════════════════════════

OPÇÃO A: Vercel (Mais fácil - RECOMENDADO)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. Fazer push para GitHub:
     git push

  2. Ir para: https://vercel.com/new

  3. Importar repositório

  4. Adicionar variáveis de ambiente

  5. Deploy! 🎉

  Seu site estará online em 2-5 minutos


OPÇÃO B: Servidor próprio
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. npm install
  2. npm run build
  3. NODE_ENV=production npm start

  Consulte PRODUCTION_READY.md para mais detalhes
