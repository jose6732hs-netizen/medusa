└──────────────────────────────────────────────────────────────────────────────┘

   1️⃣  npm install
       └─ Instala todas as dependências

   2️⃣  cp .env.example .env.local
       └─ Cria arquivo de configuração

   3️⃣  [Edite .env.local]
       └─ Configure DATABASE_URL

   4️⃣  npm run db:push
       └─ Cria as 11 tabelas no banco

   5️⃣  npm run dev
       └─ Roda em http://localhost:3000

┌──────────────────────────────────────────────────────────────────────────────┐
│ ENDPOINTS DE API CRIADOS                                                     │
└──────────────────────────────────────────────────────────────────────────────┘

   Autenticação:
   POST   /api/auth/register         • Registrar usuário
   POST   /api/auth/login            • Fazer login

   Lojas:
   GET    /api/stores                • Listar lojas do user
   POST   /api/stores                • Criar loja
   GET    /api/stores/[id]           • Detalhes da loja
   PUT    /api/stores/[id]           • Editar loja
   DELETE /api/stores/[id]           • Deletar loja

   Produtos:
   GET    /api/products              • Listar produtos
   POST   /api/products              • Criar produto
   GET    /api/products/[id]         • Detalhes
   PUT    /api/products/[id]         • Editar
   DELETE /api/products/[id]         • Deletar

   Carrinho:
   GET    /api/cart                  • Ver carrinho
   POST   /api/cart                  • Adicionar item
   PUT    /api/cart/[itemId]         • Atualizar quantidade
   DELETE /api/cart/[itemId]         • Remover item

   Checkout:
   POST   /api/checkout              • Criar pedido

   Pedidos:
   GET    /api/orders                • Listar pedidos
   GET    /api/orders/[id]           • Detalhes do pedido
   PUT    /api/orders/[id]           • Atualizar status

   Analytics:
   GET    /api/analytics             • Métricas de vendas
