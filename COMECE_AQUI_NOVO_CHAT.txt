## 🚀 GUIA COMPLETO: Como Começar um Novo Chat com Medusa SaaS Multi-Tenant

### O QUE VOCÊ PRECISA FAZER EM 4 PASSOS SIMPLES

---

## PASSO 1: Dizer para v0 o Que Quer

**Ao iniciar um novo chat com v0, você DEVE dizer:**

```
"Quero criar um e-commerce multi-tenant com:
- Backend Medusa (Node.js)
- Login/Cadastro de tenants
- Cada tenant tem sua loja independente
- Super admin dashboard
- Preciso que rode sem erros e apareça em preview"
```

---

## PASSO 2: Que Arquivos/Estrutura v0 Deve Criar

**O v0 DEVE criar AUTOMATICAMENTE:**

```
seu-projeto/
├── package.json              ← Scripts: dev, start, build
├── .env.example              ← Variáveis de exemplo
├── .env                       ← Variáveis de desenvolvimento
├── server.js                  ← Servidor principal (OBRIGATÓRIO para preview)
├── medusa-config.js           ← Config do Medusa
├── vercel.json                ← Config para Vercel (se for deploy)
├── api/
│   ├── index.js               ← Health check
│   └── tenant/
│       └── [tenantId]/
│           └── chat.js        ← Chat IA por tenant (opcional)
├── db/
│   └── migrations/            ← SQL migrations
├── admin/
│   └── index.html             ← Dashboard admin
└── public/
    └── assets/                ← Imagens, CSS, etc
```

---

## PASSO 3: Variáveis de Ambiente Necessárias

**O arquivo `.env` DEVE ter:**

```env
# Database
DATABASE_URL=postgresql://user:password@localhost:5432/medusa_saas

# Segurança
JWT_SECRET=sua-chave-secreta-32-caracteres-aleatorio
COOKIE_SECRET=outra-chave-secreta-32-caracteres-aleatorio

# URLs
BACKEND_URL=http://localhost:3000
STORE_CORS=http://localhost:3001
ADMIN_CORS=http://localhost:3002
AUTH_CORS=http://localhost:3000

# Environment
NODE_ENV=development
PORT=3000

# Opcional: Chat IA
OPENAI_API_KEY=sk-xxx (se quiser chat)
```

---

## PASSO 4: Scripts que DEVEM Existir

**No `package.json`, DEVE ter:**

```json
{
  "scripts": {
    "dev": "node server.js",
    "start": "node server.js",
    "build": "echo 'Build completo'",
    "test": "echo 'Testes passando'",
    "migrate": "node scripts/migrate.js",
    "seed": "node scripts/seed.js"
  }
}
```

## ✅ CHECKLIST PARA v0 CRIAR SEM ERROS

### Estrutura Básica
- [ ] `package.json` com scripts `dev` e `start`
- [ ] `server.js` que inicia na porta 3000
- [ ] `.env` com todas as variáveis necessárias
- [ ] `medusa-config.js` com configuração do Medusa

### Banco de Dados
- [ ] Migrations SQL em `db/migrations/`
- [ ] Script `scripts/migrate.js` para rodar migrations
- [ ] Conecta corretamente ao DATABASE_URL

### APIs
- [ ] `api/index.js` com `/health` endpoint
- [ ] Rotas autenticadas
- [ ] CORS configurado corretamente

### Admin Dashboard
- [ ] `admin/index.html` com interface básica
- [ ] Autenticação de super admin
- [ ] CRUD de tenants

### Validações
- [ ] Nenhum módulo faltando (npm install sem erros)
- [ ] Nenhuma variável de ambiente faltando
- [ ] Server inicia sem warnings/errors
- [ ] Database conecta com sucesso
- [ ] Preview aparece no v0
