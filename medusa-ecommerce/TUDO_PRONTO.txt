  1️⃣  Configure .env.local
      └─ cp .env.example .env.local
      └─ Edite DATABASE_URL com Neon
      └─ Gere NEXTAUTH_SECRET

  2️⃣  Instale dependências
      └─ npm install

  3️⃣  Setup banco de dados
      └─ npm run db:push

  4️⃣  Inicie desenvolvimento
      └─ npm run dev

  5️⃣  Acesse no navegador
      └─ http://localhost:3000

  OPÇÃO 1: Vercel (RECOMENDADO - Mais fácil)
  ───────────────────────────────────────────
    1. git push seu repositório
    2. Ir em https://vercel.com/new
    3. Importar repositório
    4. Adicionar variáveis de ambiente
    5. Click Deploy!
    ✨ Seu site estará online em 2-5 minutos


  OPÇÃO 2: Servidor próprio
  ────────────────────────
    1. npm install
    2. npm run build
    3. NODE_ENV=production npm start
    (Veja PRODUCTION_READY.md para detalhes)
