🎯 COMO COMEÇAR EM 5 PASSOS:

PASSO 1: Ler Documentação (5 min)
   → Abra: QUICK_START_MULTITENANT.md
   → Entenda os próximos passos

PASSO 2: Configurar Environment (2 min)
   → cd packages/multitenant-admin
   → cp .env.example .env.local
   → Edite .env.local com seu DATABASE_URL (Neon)

PASSO 3: Instalar Dependências (3 min)
   → npm install
   → Aguarde a instalação

PASSO 4: Setup Super Admin (2 min)
   → npm run setup
   → Cria você como admin com bcrypt seguro

PASSO 5: Iniciar Desenvolvimento (1 min)
   → npm run dev
   → Acesse http://localhost:3001
   → Faça login com:
      Email: admin@multitenant.com
      Senha: admin123456

TEMPO TOTAL: ~15 minutos até estar funcionando!

❓ DÚVIDAS FREQUENTES:

P: Como criar um novo tenant?
R: Após login, clique em "Tenants" → "Novo Tenant"

P: Como adicionar usuários?
R: Vá em "Usuários" → "Novo Usuário" (vinculado a um tenant)

P: Como mudar senhas?
R: Edite lib/auth.ts para implementar endpoint de reset

P: Como integrar pagamentos?
R: Veja DEPLOYMENT_GUIDE.md → Phase 2

P: Qual é o custo?
R: Backend grátis (Neon free tier)
   Frontend grátis (Vercel free tier até 100k requisições)
   Escale conforme crescer
