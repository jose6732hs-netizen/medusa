🚀 INICIAR O PROJETO (3 COMANDOS)

  1. Instale as dependências:
     $ pnpm install

  2. Configure o banco de dados (execute migrações):
     $ pnpm medusa migrations run

  3. Inicie o servidor em desenvolvimento:
     $ pnpm dev
