ENDPOINTS DISPONÍVEIS
=====================

1. GET /
   Descrição: Página de info do Medusa monorepo
   Resposta: HTML com versão, pacotes, links

2. GET /health
   Descrição: Health check endpoint
   Resposta: JSON com status, timestamp, uptime
   Status 200: Ok (database conectado)
   Status 503: Unhealthy (database não conectado)

   Exemplo:
   $ curl https://api.exemplo.com/health
   {
     "status": "ok",
     "timestamp": "2025-03-22T10:30:00.000Z",
     "environment": "production",
     "uptime": 3600
   }

VARIÁVEIS DE AMBIENTE OBRIGATÓRIAS
===================================

DATABASE_URL
  - PostgreSQL connection string
  - Deve incluir sslmode=require em produção
  - Exemplo: postgresql://user:pass@host/db?sslmode=require

JWT_SECRET
  - Secret para assinar tokens JWT
  - Mínimo 32 caracteres
  - Gerado por: openssl rand -hex 16

COOKIE_SECRET
  - Secret para assinar cookies
  - Mínimo 32 caracteres
  - Gerado por: openssl rand -hex 16

STORE_CORS
  - URL da loja frontend
  - HTTPS em produção
  - Exemplo: https://store.seuloja.com

ADMIN_CORS
  - URL do painel admin
  - HTTPS em produção
  - Exemplo: https://admin.seuloja.com

AUTH_CORS
  - URL de autenticação
  - HTTPS em produção
  - Exemplo: https://auth.seuloja.com

BACKEND_URL
  - URL base do backend
  - HTTPS em produção
  - Exemplo: https://api.seuloja.com

NODE_ENV
  - Ambiente (development ou production)
  - Em produção: "production"
